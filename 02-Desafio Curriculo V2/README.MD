# Desafio Currículo V2 🎨

Evolução do desafio de currículo, desenvolvido durante o módulo
de **Introdução ao CSS**.

## 🎯 Objetivo
Aplicar estilização básica em um currículo HTML, melhorando
a apresentação visual do conteúdo.

## 🛠️ Tecnologias utilizadas
- HTML5
- CSS

## 📚 Conceitos praticados
- CSS básico
- Cores, fontes e espaçamento
- Separação entre estrutura (HTML) e estilo (CSS)
