# Projeto CSS Início 🧱

Projeto desenvolvido durante o módulo de **estrutura semântica
e posicionamento**.

## 🎯 Objetivo
Praticar o uso de tags semânticas do HTML e conceitos iniciais
de posicionamento com CSS.

## 🛠️ Tecnologias utilizadas
- HTML5
- CSS

## 📚 Conceitos praticados
- Tags semânticas (header, nav, main, section, footer)
- Organização estrutural da página
- Posicionamento básico de elementos
