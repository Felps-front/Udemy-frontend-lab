# Projeto Lista de Contatos 📇

Projeto desenvolvido durante o módulo de **Flexbox**.

## 🎯 Objetivo
Criar uma lista de contatos organizada e responsiva utilizando
o modelo de layout Flexbox.

## 🛠️ Tecnologias utilizadas
- HTML5
- CSS (Flexbox)

## 📚 Conceitos praticados
- Display flex
- Alinhamento e distribuição de elementos
- Organização de layout responsivo
