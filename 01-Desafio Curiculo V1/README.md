# Desafio Currículo V1 🧾

Projeto desenvolvido durante o módulo de **Introdução ao HTML**
em curso da Udemy.

## 🎯 Objetivo
Criar a estrutura inicial de um currículo utilizando apenas HTML,
aplicando as principais tags e a organização básica de conteúdo.

## 🛠️ Tecnologias utilizadas
- HTML5

## 📚 Conceitos praticados
- Estrutura base do HTML
- Títulos, parágrafos e listas
- Organização de informações em página web
