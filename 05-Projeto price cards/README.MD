# Projeto Price Cards 💳

Projeto prático integrando diversos conceitos aprendidos ao longo
do curso.

## 🎯 Objetivo
Desenvolver cards de preços aplicando estrutura HTML,
estilização com CSS e organização de layout.

## 🛠️ Tecnologias utilizadas
- HTML5
- CSS

## 📚 Conceitos praticados
- Estruturação de componentes
- Estilização com CSS
- Layout e alinhamento
- Integração de múltiplos conceitos
